1.1.4. cleaning

  • we need three columns: summary, notes, bill type
    • examine each column to look for inconsistencies
    • what do we need to clean from each column, if at all?

Start with Bill Type. What are the most frequent values for this column? 

df["Bill Type"].value_counts()

There are 218 different labels. That's because we have examples like the one below. We need to cut these down.

"DEI Ban" "DEI Ban " " DEI Ban" "DEI Ban "

First, preserve the original. 

df["Bill Type Raw"] = df["Bill Type"]

Then, let's split up the long string into individual ones. 

df["Bill Type"].str.split("/")

Now, create a new column for the split labels. 

  df["bill_type_labels"] = (
    df["Bill Type"]
    .fillna("")
    .str.split("/")
)

Use strip() to remove white spaces. 

def clean_labels(labels):
  return [label.strip() for label in labels]

df["bill_type_labels"] = df["bill_type_labels"].apply(clean_labels)

Make the difference between these two columns visible. 

print(df["Bill Type Raw"].iloc[0])
print(df["bill_type_labels"].iloc[0])

Now, to pull out the individual lable, use explode() 

labels = df["bill_type_labels"].explode()

We can ask how many times each label is used! 

labels.value_counts()
labels.unique()
# see the comparison between the original and our new categories.
len(labels.unique())
len(df['Bill Type Raw'].unique())

Are there any other cleaning steps we'd want to do?

1.1.5. Final step — MultiLabelBinarizer

To train a classifier, we would create a "sparse" matrix. A sparse matrix has 0s and 1s to indicate the presence of a category.

We will use the library sklearn. 

from sklearn.preprocessing import MultiLabelBinarizer

mlb = MultiLabelBinarizer()

Y = mlb.fit_transform(df["bill_type_labels"])

This creates an mlb object and Y object. The first contains our classes, and the second is our matrix. 

# all of our unique labels
mlb.classes_

# scary matrix...
Y

# see that we have the same number of rows as bills
# and we have the same number of columns as labels!!
Y.shape()

1.1.6. our workflow

RAW BILL TYPE │ ▼ Preserve original │ ▼ Inspect values │ ▼ Split on "/" │ ▼ Clean whitespace │ ▼ Inspect individual labels │ ▼ MultiLabelBinarizer │ ▼ 0 / 1 matrix

  • create one column for all text
  • create a sparse dataset for the bill types

First, we will create one column "text" to hold all of our text features. 

df["text"] = (
  df["Summary"].fillna("") + " " +
  df["Notes"].fillna("")
)

Notice that some values are single, other are multiple. This is a problem – our model wouldn't be able to differentiate one from three in one.

First, we will split the labels and put them in a separate column. 

df["bill_type_labels"] = (
  df["Bill Type"]
  .fillna("")
  .str.split(" / ")
)

Then, we will use sklearn.preprocessing library to turn these labels into a sparse dataset. 

from sklearn.preprocessing import MultiLabelBinarizer

mlb = MultiLabelBinarizer()

Y = mlb.fit_transform(df["bill_type_labels"])
