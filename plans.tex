\subsubsection{introduction to k-means algorithm}
\label{sec:org8c3c3b4}

k-means is a new algorithm, different from the
regression/classification work you've already been doing:

> \textbf{\textbf{Linear regression:}} predict a number, supervised.
\begin{itemize}
\item predicts the slope of a line, linear relation between x -> y
\end{itemize}

> \textbf{\textbf{Logistic regression:}} predict a category/class, supervised.
\begin{itemize}
\item predicts the decision boundary between two types, y is true/false.
\end{itemize}

> \textbf{\textbf{K-means:}} predict clusters, unsupervised.
\begin{itemize}
\item predicts where to draw y lines to create groupings of data x.
\end{itemize}

These different algorithms work on different spreads of data, and
different question of prediction.

A note on unsupervised learning:
\begin{itemize}
\item \textbf{\textbf{K-means doesn't know what the groups mean. It only knows which
observations are similar to one another.}}
\item the difference between \textbf{\textbf{a computationally produced grouping and an
interpretive category}}.
\end{itemize}

\subsubsection{intuition on the "centroid"}
\label{sec:orgc082974}
Imagine three clusters of dots.

K-means essentially does this:

\begin{enumerate}
\item Pick `k` centers. (random)
\item Assign each data point to the nearest center.
\item Move each center to the middle of its assigned data points.
\item Repeat.
\item Stop when the centers aren't changing much.
\end{enumerate}

You can describe the algorithm without equations:
\begin{itemize}
\item initialize centers randomly
\item assign points to nearest center
\item move centers to be in the middle of the assigned points
\item re-assign points
\item re-move centers
\end{itemize}

The iterative nature is much easier to understand visually than
mathematically.

\subsubsection{introduce `K`}
\label{sec:org90113ff}
How many groups should we look for?
\begin{itemize}
\item that's where `k` comes in.
\item K is the number of clusters we are asking the algorithm to find.
\end{itemize}

At first, k = 3.
\begin{itemize}
\item However, K-means doesn't automatically know that there are three
meaningful groups. We tell it to look for three.
\end{itemize}

\subsubsection{do it in Python}
\label{sec:orgded4181}

\begin{verbatim}
from sklearn.cluster import KMeans

X = df[["age", "annual_income"]]

model = KMeans(n_clusters=3, random_state=42)

model.fit(X)
\end{verbatim}

Then create a new column for cluster labels

\begin{verbatim}
df["cluster"] = model.labels_
df

\end{verbatim}

What does cluster 1 mean?
\begin{itemize}
\item We don't know yet
\item The algorithm has created the grouping
\item But we have to interpret it.
\end{itemize}

Let's make the clustering visible.

\begin{verbatim}
plt.scatter( df["age"], df["annual_income"], c=df["cluster"])

plt.xlabel("Age")
plt.ylabel("Annual income")
plt.show()
\end{verbatim}

Now that you can see the groups, does this look like a reasonable
grouping?

What does each cluster represent? Calculate group characteristics.

\begin{verbatim}
df.groupby("cluster")[["age", "annual_income"]].mean()
\end{verbatim}

Now start to interpret:
\begin{itemize}
\item Cluster 0 = older/lower income
\item Cluster 1 = younger/lower income
\item Cluster 2 = middle-aged/higher income
\end{itemize}

Those labels are our interpretation, not something k-means discovered.

\subsubsection{scaling \& comparing}
\label{sec:org63c638a}
It is important to scale values, like we did with logistic regression
\begin{itemize}
\item the high numbers of the salary are affecting the creation of the
clusters
\begin{itemize}
\item the numbers we give an algorithm affect the patterns it sees.
\item we need to scale the larger values, like income
\end{itemize}
\item K-means uses \textbf{\textbf{distance}}, so income can dominate the calculation.
\end{itemize}

Introduce:

\begin{verbatim}
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

X_scaled = scaler.fit_transform(X)

X_scaled # compare to just X
\end{verbatim}

Then, re-train the model.

\begin{verbatim}
model = KMeans(n_clusters=3, random_state=42)

model.fit(X_scaled)

df["cluster"] = model.labels_  model = KMeans(n_clusters=3, random_state=42)

model.fit(X_scaled)

df["cluster"] = model.labels_
\end{verbatim}

Now, compare the plots.

\begin{verbatim}
plt.scatter( df["age"], df["annual_income"], c=df["cluster"])

plt.xlabel("Age")
plt.ylabel("Annual income")
plt.show()
\end{verbatim}

\subsubsection{question: does k-means discover groups, or does it construct groups?}
\label{sec:org2a733b9}

K-means:
\begin{itemize}
\item doesn't know what a group means
\item doesn't know whether the grouping is socially meaningful
\item doesn't know whether the features are appropriate
\item doesn't know whether `k = 3` is conceptually justified
\item doesn't know whether the data itself reflects bias
\item simply optimizes a mathematical criterion based on the
representations we provide
\end{itemize}

So the computational output isn't the end of the analysis. The
interpretation comes afterward.

\subsection{decision tree intuition}
\label{sec:orgf788450}
\begin{itemize}
\item create a graph of when you can go skiing in different parts of the
world.
\begin{itemize}
\item latitude on the Y axis; month of the year on the X axis
\end{itemize}
\item create splits of the data, and write conditions for each
split
\begin{itemize}
\item first, create condition of \textbf{y > 30}
\begin{itemize}
\item this is the first split of the decision tree.
\end{itemize}
\item then, in that subgroup, split off \textbf{x < 3}.
\begin{itemize}
\item this is the second split in the decision tree.
\end{itemize}
\item so, if y > 30  \&\& x < 3, then yes you can ski.
\item you begin to partition out the dataset this way.
\begin{itemize}
\item by asking questions about each quantrant, you fill out the
decision tree.
\end{itemize}
\end{itemize}
\item what is a random forrest?
\begin{itemize}
\item a collection of decision trees.
\item decision trees tend to overfit, which means they predict only what
they have seen in their training data, they don't generalize.
\end{itemize}
\end{itemize}
