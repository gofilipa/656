\subsubsection{cleaning}
\label{sec:orgc78b895}
\begin{itemize}
\item we are looking to predict bill type based on summary and notes
\item we need three columns: summary, notes, bill type
\begin{itemize}
\item spend a couple of minutes looking at the column. Check for
inconsistencies, things we'd want to standardize or regularize.
\item what do we need to clean from each column, if at all?
\end{itemize}
\end{itemize}

We can also use pandas to do this programmatically. What are the most
frequent values for this column?

\begin{verbatim}
df["Bill Type"].value_counts()
\end{verbatim}

There are 298 different labels. That's because we have examples like
the one below. 

\begin{quote}
"DEI Ban"
"DEI Ban "
" DEI Ban"
"DEI Ban  "
\end{quote}

So we decide that we want to cut down the inconsistent labels. First,
preserve the original.

\begin{verbatim}
df["Bill Type Raw"] = df["Bill Type"]
\end{verbatim}

Second, let's split up the long string into individual ones.

\begin{verbatim}
df["Bill Type"].str.split("/")
\end{verbatim}

Third, create a new column for the split labels. 

\begin{verbatim}
df["bill_type_labels"] = df["Bill Type"].str.split("/").fillna("")
\end{verbatim}

Fourth, strip() to remove white spaces.

\begin{verbatim}
def clean_labels(labels):
  return [label.strip() for label in labels]

df["bill_type_labels"] = df["bill_type_labels"].apply(clean_labels)
\end{verbatim}

Make the difference between these two columns visible.

\begin{verbatim}
print(df["Bill Type Raw"].iloc[0])
print(df["bill_type_labels"].iloc[0])
\end{verbatim}

Fifth, pull out the individual label, use \texttt{explode()}

\begin{verbatim}
labels = df["bill_type_labels"].explode()
\end{verbatim}

We can ask how many times each label is used!

\begin{verbatim}
labels.value_counts()
labels.unique()
# see the comparison between the original and our new categories.
len(labels.unique())
len(df['Bill Type Raw'].unique())
\end{verbatim}

Are there any other cleaning steps we'd want to do?
\begin{itemize}
\item remove labels that appear 1 time? less than 3 times?
\end{itemize}

\subsubsection{final step — MultiLabelBinarizer}
\label{sec:org8326a48}
To train a classifier, we would create a "sparse" matrix. A sparse
matrix has 0s and 1s to indicate the presence of a category.

We will use the library \texttt{sklearn}.

\begin{verbatim}
from sklearn.preprocessing import MultiLabelBinarizer

mlb = MultiLabelBinarizer()

Y = mlb.fit_transform(df["bill_type_labels"])
\end{verbatim}

This creates an \texttt{mlb} object and \texttt{Y} object. The first contains our
classes, and the second is our matrix.

\begin{verbatim}

# all of our unique labels
mlb.classes_

# scary matrix...
Y

# see that we have the same number of rows as bills
# and we have the same number of columns as labels!!
Y.shape()

\end{verbatim}
