\subsection{GPT models}
\label{sec:orgec9eaf7}
GPT and BERT are two of the most influential architectures in natural
language processing but they are built with different design goals.


GPT is an \textbf{\textbf{autoregressive}} model that generates text by predicting
the next word,

while BERT is a \textbf{\textbf{bidirectional}} model that understands context from
both directions making it better for comprehension tasks.

BERT
\begin{itemize}
\item bidirectional
\begin{itemize}
\item forward and backward
\end{itemize}
\item encoder
\begin{itemize}
\item Masked Language Modeling (training objective)
\end{itemize}
\item representations from
\item transformers
\begin{itemize}
\item attention mechanism
\end{itemize}
\item This bidirectional attention allows BERT to understand the full
context of a sentence at once rather than processing it
sequentially.
\begin{itemize}
\item Good for: Sentiment analysis, question answering, classification
\end{itemize}
\end{itemize}

GPT
\begin{itemize}
\item generative
\begin{itemize}
\item next word prediction
\item "decoder"
\item Causal Language Modeling (training objective)
\end{itemize}
\item pre-trained
\begin{itemize}
\item unsupervised (trained on unlabeled data)
\end{itemize}
\item transformer
\begin{itemize}
\item atttention mechanism
\end{itemize}
\item Like BERT, GPT also starts with text and positional embeddings and
processes them through transformer layers of attention, Add and Norm
and feed forward networks.
\item But its additional decoder architecture makes GPT excel at text
generation since it naturally learns to predict the next word in a
sequence.
\begin{itemize}
\item Good for:
\begin{itemize}
\item Story writing, chatbots, code generation, creative tasks
\end{itemize}
\end{itemize}
\end{itemize}
