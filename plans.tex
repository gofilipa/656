Peer Review Checklist
\begin{itemize}
\item abstract
\item introduction
\begin{itemize}
\item presents the urgency of the topic
\item sets a particular angle for approaching the topic
\end{itemize}
\item relevant literature
\begin{itemize}
\item covers the topic's scope
\item indicates highlights from prior work
\end{itemize}
\item methodology
\begin{itemize}
\item clear sense of individual steps
\end{itemize}
\item results/analysis
\item discussion
\item conclusion
\begin{itemize}
\item wraps up the main points / argument
\item ends with a big picture statement (why this matters) or with a
pointer to future work
\end{itemize}
\end{itemize}
