\subsection{python challenge, 30}
\label{sec:orgdd73547}
Write some python code that contains the following components below.
Try to do it without a coding tool. But if you must, know that you
will have to explain (and therefore know) what each line of code is
doing.

Required:
\begin{itemize}
\item a loop
\item a list
\item a function
\end{itemize}

One solution:
\begin{verbatim}
import random
def greeting(name):
    greetings = [
        "how are you doing today?",
        "what's up?",
        "como te sientes?",
        "what's shakin'?",
        "tudo bem?"
    ]
    print(f"Hello {name}, {random.choice(greetings)}")

greeting('Filipa')
\end{verbatim}

\begin{verbatim}
Hello Filipa, como te sientes?
\end{verbatim}
